# Portfolio Website — Oasis Infobyte (OIB-SIP)

A modern, fully responsive personal portfolio website built as part of the **Oasis Infobyte Virtual Internship Program (OIB-SIP)** under the **Web Development & Design** track (**Level 1 - Task 2**).

---

## 📌 Project Overview

This project serves as an interactive personal showcase highlighting software engineering skills, featured web projects, technical expertise, and contact information. It is designed with clean visual hierarchy, intuitive navigation, and smooth user interaction.

## ✨ Key Features

- **Responsive Design:** Optimized for seamless display across desktop, tablet, and mobile screens.
- **Project Showcase:** Interactive layout displaying recent web applications with direct links to live demos and GitHub code.
- **Skills Matrix:** Categorized overview of frontend, backend, and development tools.
- **Contact Form:** Integrated input fields with front-end validation for user inquiries.
- **Smooth Navigation:** Fixed header with smooth-scrolling navigation links.

## 🛠️ Tech Stack

- **HTML5:** Semantic structural layout and accessibility markup.
- **CSS3 / SCSS:** Modern styling using Flexbox, CSS Grid, media queries, and clean component architecture.
- **JavaScript (ES6+):** Dynamic DOM manipulation, menu toggles, and interactive elements..
