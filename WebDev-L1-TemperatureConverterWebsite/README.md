# Temperature Converter Website — Oasis Infobyte (OIB-SIP)

A responsive, dynamic web application that performs real-time unit conversions between Celsius, Fahrenheit, and Kelvin. Built as part of the **Oasis Infobyte Virtual Internship Program (OIB-SIP)** under the **Web Development & Design** track (**Level 1 - Task 3**).

---

## 📌 Project Overview

This project provides a clean and intuitive interface for converting temperature values across different scales instantly. It features input validation to handle edge cases like absolute zero and ensures accurate calculations using standard mathematical conversion formulas.

## ✨ Key Features

- **Real-time Conversion:** Instant calculations between Celsius (°C), Fahrenheit (°F), and Kelvin (K).
- **Input Validation:** Built-in safeguards to validate numeric input and handle values below absolute zero ($0\text{ K} / -273.15^\circ\text{C}$).
- **Responsive UI:** Clean, centered card layout designed for seamless user experience across mobile, tablet, and desktop devices.
- **Clear & Reset Controls:** Quick-reset options to clear input fields and recalculate values effortlessly.

## 🛠️ Tech Stack

- **HTML5:** Semantic form controls, structural elements, and accessible input types.
- **CSS3:** Modern styling, flexbox/grid alignment, smooth transitions, and custom UI components.
- **JavaScript (ES6+):** DOM event handling (`addEventListener`), conversion mathematical logic, and dynamic string rendering.
