# Level 2 - Task 2: Tribute Page — Andrei Tarkovsky (Oasis Infobyte Internship)

This project was developed as part of the **Oasis Infobyte Web Development & Designing Internship (OIBSIP)** under **Level 2 — Task 2: Tribute Page**.

The website is a modern, interactive, and aesthetically crafted tribute page dedicated to the life, poetic cinema philosophy, career timeline, and iconic masterpieces of the legendary filmmaker **Andrei Tarkovsky**.

---

## 📌 Task Details & Requirements

- **Subject:** Andrei Tarkovsky (Film Director)
- **Track:** Web Development & Designing
- **Level:** Level 2
- **Task:** Task 2 — Tribute Page
- **Tech Stack:** HTML5, CSS3, JavaScript (Vanilla ES6+)

### 📋 Feature Checklist (Task Requirements)

- [x] **Page Title & Tagline:** Clear header showcasing Andrei Tarkovsky's name and cinematic tagline.
- [x] **Featured Media:** Prominently displayed portrait centered within a responsive layout.
- [x] **Biography / Tribute Section:** Detailed 4-part biographical breakdown covering Tarkovsky's early life, philosophy, masterpieces, and legacy.
- [x] **Timeline / Key Achievements:** Styled timeline section documenting major film releases and milestones (e.g., *Solaris*, *Stalker*, *Mirror*).
- [x] **Quote Block:** Distinctly styled quote block featuring famous statements by Tarkovsky.
- [x] **Color Palette & Typography:** Dual-font configuration (`Cinzel` for headings, `Plus Jakarta Sans` for body) with dark cinematic theme and gold accents (`#d4af37`).
- [x] **Fully Responsive Layout:** Optimized across mobile, tablet, and desktop viewports using CSS Grid and Flexbox.

---

## 🚀 Interactive Enhancements

- **Symmetrical 3x3 Grid Layout:** Symmetrically aligned text blocks surrounding Tarkovsky's central portrait in the "About" section.
- **Dynamic 3D-Tilt Effect:** Interactive cards react dynamically to mouse movement for 3D spatial depth.
- **Scroll Reveal Animations:** Built with `IntersectionObserver` for smooth entrance animations on scroll.
- **Active Navigation Tracking:** Dynamic navbar highlighting based on current scroll position.
