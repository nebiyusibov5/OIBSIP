# Web Development - Level 1: Landing Page

This repository contains the **Landing Page** project developed as part of the **Oasis Infobyte Virtual Internship Program (OIBSIP)**.

---

## 📌 Project Overview
**LyakGo** is a responsive multi-page web application designed for a postal and courier delivery service. The goal of this project was to create a modern, user-friendly interface featuring dynamic layouts, rate cards, interactive sliders, and structured navigation.
