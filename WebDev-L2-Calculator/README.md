# Calculator Web Application — Oasis Infobyte (OIB-SIP)

A modern, responsive browser-based calculator featuring clean UI design, chained arithmetic operations, and strict input validation. Built as part of the **Oasis Infobyte Virtual Internship Program (OIB-SIP)** under the **Web Development & Design** track (**Level 2 - Task 1**).

---

## 📌 Project Overview

This project is a fully functional web calculator designed to perform basic mathematical calculations with accuracy and speed. It handles continuous operator chaining, dynamic display updates, and edge cases like division by zero using clean vanilla JavaScript algorithms.

## ✨ Key Features

- **Standard Operations:** Addition, subtraction, multiplication, and division.
- **Operator Chaining:** Perform multi-step expressions sequentially without breaking logic flow.
- **Error & Edge Case Handling:** Built-in validation to manage zero-division errors and prevent multiple decimal points.
- **Clear & Delete Functions:** Quick button controls to remove the last character or reset the entire calculation state.
- **CSS Grid Layout:** Perfectly aligned button grid with responsive resizing for mobile and desktop screens.

## 🛠️ Tech Stack

- **HTML5:** Semantic element structure and accessible button layout.
- **CSS3:** CSS Grid, Flexbox, custom variables, and interactive hover/active button states.
- **JavaScript (ES6+):** DOM manipulation, event listeners (`addEventListener`), mathematical evaluation logic, and state management.
